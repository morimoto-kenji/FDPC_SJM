■■■■■ はじめに

　ＦＤは A.Idei 氏が作られたファイル管理ツールです。PC-9801 版の FD は
Ver.2.32 のあと、ARGON 氏の「ＦＤ３０」によって 30 行計画などに対応し、
さらに「城」氏の「ＦＤ９８ パッチＳＪ」によって、長いファイル名，CD-ROM，
ネットワークドライブ，Windows 95 などに対応する大きな拡張を受けて、長く
使い続けられてきました。

　この 2.32SJ.M は、その FD98 2.32SJ を PC/AT 互換機の日本語 DOS/V で使える
ようにしたものです。FD そのものはもちろん、ＦＤ３０，ＳＪパッチの機能と
使い勝手は、すべて三氏の長年の仕事によるものです。改変は DOS/V で動かす
ために必要な部分と、正しく動かすための最小限の不具合修正（６．を参照）に
とどめ、キーの対応や使えなくなる機能の扱いは、原作者
A.Idei 氏が Ver.3.12/3.13 で示された PC-98 版と DOS/V 版の違いに倣いました。

　なお、これは純粋なＳＪパッチではないため、名称を「SJ.M」としています。
本差分について、三氏へのお問い合わせはご遠慮ください。


■■■■■ １．概要

　FD Ver.2.32 for PC-9801 のオリジナルファイルに、この差分（FDPC_SJM.BDF）を
BUPDATE で当てると、DOS/V 版の FD.COM，FD98.COM，FDCUST2.COM，FD.CFG が
できます。ＦＤ３０，ＳＪの差分を先に当てる必要はありません（この差分に
含まれています）。

　FD98.COM の処理はほぼそのままで、PC-98 の画面・キーボード・コンソールを
DOS/V 上で模擬する部分を FD.COM に追加しています（しくみは SJMTECH.DOC）。


■■■■■ ２．必要なファイル

	1  FD98_232.LZH		FD Ver.2.32 for PC-9801（オリジナル）
	2  BDIFF128.LZH		BDIFF/BUPDATE 1.28（BUPDATE.EXE を使用）
	3  FDPC_SJM.BDF		この差分

　FD98_232.LZH から取り出した次の４ファイルを使います。

	FD       COM     1900  91-07-05   2:32
	FD98     COM    36212  91-07-05   2:32
	FDCUST2  COM     1754  91-07-05   2:32
	FD       CFG     5308  91-07-05   2:32

　BUPDATE はファイルの日付・長さ・チェックサムを照合します。日付が変わって
いると当たらないので、アーカイブから取り出したままのファイルを使ってください。
次のような場合は、日付や長さが元のままでも中身が変わっていて当たりません。
アーカイブから取り出し直してください。

	・FDCUST2 を一度でも実行した FD98.COM（カスタマイズの値が書き込まれ
	  ます）
	・編集した FD.CFG（自分の設定は別の名前で残しておき、差分を当てた後
	  に FD.CFG にして FDCUST2 を実行します）

　途中で失敗した場合も、できかけのファイル（FD.COM，.ORG，.000 など）を
消して、４ファイルを取り出し直してからやり直してください。


■■■■■ ３．インストール

　上記の４ファイル，FDPC_SJM.BDF，BUPDATE.EXE を同じディレクトリに置いて、
コマンドラインから次のように実行します。

	A>BUPDATE FDPC_SJM

　FD.COM は「オリジナル→ＦＤ３０→ＳＪ→2.32SJ.M」の順に、差分ファイルの
中で段階的に更新されます。元のファイルは .ORG，.000 などの名前で残ります。

	FD       COM    40039
	FD98     COM    60187
	FDCUST2  COM     2527
	FD       CFG     7672

ができれば完了です。FD.CFG はＦＤ３０で拡張された内容になります。

　BUPDATE は元のファイルを「名前.ORG」として残し、すでに .ORG があると
それを .000，.001 … に移します。FD.COM と FD.CFG は名前が同じなので、
最後に残る FD.ORG は元の FD.CFG で、FD.COM の元のファイルは FD.000～
FD.002 になります。これらは動作には使いませんので、消してかまいません。

　自分の FD.CFG を使う場合は、差分を当てた後に FD.CFG と置き換えて FDCUST2
を実行してください。ＳＪの追加項目（pack2，n_pack，copy13，err24）は、
配布の FD.CFG には含まれていません。使う場合はＳＪの説明書（FD98.TXT）を
見て、FD.CFG の最後に書き足してください（SJMUSAGE.DOC も参照）。

	*--- 注意 ------------------------------------------------------*
	|  差分当ての作業は、必ずコマンドラインで行ってください。	|
	|  FD の子プロセスから行うと、正常に更新できないことが	|
	|  あります。（ＦＤ３０，ＳＪと同じです）			|
	*---------------------------------------------------------------*

　できた４ファイルを PATH の通ったディレクトリに置いてください。FD98.COM は
FD.COM から起動されるファイルで、単独では起動しません。


■■■■■ ４．使い方

◆◆◆◆ ４．１  起動と終了

	A>FD

で起動します。[Q] のあと [Y] で終了します。操作の詳細は FD.DOC（オリジナル）
と、ＦＤ３０，ＳＪの機能をまとめた SJMUSAGE.DOC を参照してください。

◆◆◆◆ ４．２  キーの対応

　FD.DOC（Ver.3.12/3.13）で原作者が示している IBM と PC-9801 のキーの対応に
従っています。

	DOS/V			PC-9801
	--------------------------------------------
	[Alt]			[GRPH]
	[Page Up]		[ROLL DOWN]
	[Page Down]		[ROLL UP]
	[Home]			[HOME CLR]
	[End]			[SHIFT] + [HOME CLR]
	[Enter]			[RET]
	[F11]			[HELP]
	[F1]～[F10]		[f･1]～[f･10]
	[無変換]，[変換]	[NFER]，[XFER]

　Ver.3.x の DOS/V 版では [Help] は [F1] ですが、2.32 では [f･1] に Logdsk が
割り当てられているため、[HELP] は [F11] にしています。[Shift]，[Ctrl] との
組み合わせは PC-98 版と同じです（例：[Ctrl] + [Home] で全てを対象にマーク）。

	[F3]  [C] Copy		コピー

	[Shift]+[F1]  [A] Attr		属性，日付の変更

	[Shift]+[F3]  [M] Move		移動

■■■■■ ５．カスタマイズ

　FD.CFG と FDCUST2.COM によるカスタマイズは PC-98 版と同じです（表示に
関わる項目は「６．PC-98 版との違い」も参照してください）。FD98.COM の
大きさや配置は変えていないので、PC-98 版で使っていた FD.CFG もそのまま使え
ます。色番号も PC-98 版と同じ（0:黒 1:青 2:赤 3:紫 4:緑 5:水色 6:黄 7:白）
です。

　入力時のヒストリ（↑↓で過去のパスやコマンドを呼び出す機能）を使うには、
FD.CFG の ems40 を 1 にして FDCUST2 を実行してください（初期値は 0）。


■■■■■ ６．PC-98 版との違い

　PC-98 のディスク BIOS を直接使う次の機能は、Ver.3.x の DOS/V 版と同様に
使えません。

	・[B]ackup（フロッピーのバックアップ）
	  「書込処理 不可能」と表示されます
	・フロッピーのボリュームラベル行での C，D，K（ディスク単位の処理）
	  通常のコピー，削除，ディレクトリ作成として動作します

　PC-98 のハードウェアに依存する次のものは、DOS/V に合わせています。

	・画面の行数は DOS/V の現在の行数に合わせます（25 行，30 行など）。
	  ハイレゾ，90 桁 BIOS，TT.COM／30 行 BIOS 関連の処理は働きません
	・罫線や枠は DOS/V の半角罫線（二重線）で表示します
	・背景色（back，Green，Red，Blue）は、近い背景色で表示します
	・色は PC-98 と同じく明るい色で表示し、リバースは明るい色の背景に
	  背景色の文字で表示します（PC-98 でグラフィック画面の背景色が
	  文字の部分に透けて見えるのと同じ見え方です）
	・アンダーライン（cursor=1 や色の +32）は DOS/V で表示できないため、
	  その色の暗い背景に明るい文字で表示します（例：黄 → 茶の背景に黄）
	・yen=1（半角＼の表示）は使えません。DOS/V の日本語フォントには
	  半角の＼がないため、￥で表示されます
	・外部コマンドの実行時と FD の終了時に画面を消去します
	  （Ver.3.x の DOS/V 版と同じ動作です）
	・ヘルプ中のキー名は DOS/V のキー名に変えています
	・グラフィック画面の表示切り替え（[Y]）は働きません
	・ＳＪ自身の不具合を１件修正しています：CD-ROM の読み込みエラー
	  （「読み込みエラー発生」）で「もう一度 <R>」を選ぶと、読み込む
	  セクタ数が壊れていて暴走していました（PC-98 版の 2.32SJ でも
	  起きます）。CD を入れ直して「もう一度」を選べば、続けて使えます


■■■■■ ７．制限事項

	・日本語 DOS/V（V-text 表示）が必要です。MS-DOS 6.2/V（25 行，30 行）
	  と、Windows 95（日本語版 OSR2.1）の MS-DOS プロンプトで動作を確認
	  しました。英語モード（CHEV US など）では、漢字や罫線が表示できず、
	  反転部分の文字が点滅するため使えません。
	・View の 20 行表示（^G）は、画面の上の 20 行を使って表示します
	  （PC-98 のように文字を縦に大きくすることはできません）。
	・入力欄の挿入／上書きモードで、カーソルの形は変わりません
	  （Ver.3.x の DOS/V 版と同じです）。
	・フロッピーや CD を取り出したまま読み込みエラーで「中止」を続ける
	  と、FD はＳＪの動作どおり終了することがあります。ＳＪの追加項目
	  err24 が 0 のとき（配布の FD.CFG のように err24 を書いていない
	  ときも同じ）は、終了時に画面を消去するため、終了の理由を示す
	  メッセージは画面に残りません。err24 が 1，2 のときは「リムーバ
	  ブルディスク所在不明！終了します」を表示してキー入力を待ちます。
	・DOSBox-X などの、DOS の内部構造（CDS）を持たない DOS 環境では
	  「ドライブの指定が違います」となり使えません。ＳＪと同じ制限です。
	・メモリはＳＪの必要量（EMS なしで約 330KB，あれば約 270KB）に加え、
	  画面の模擬用に約 21KB 使います。
	・継続コピー，クリック音などは十分に確認できていません。

などをそのまま配布・転載しないでください。
